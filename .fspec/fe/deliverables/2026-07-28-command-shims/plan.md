# Command Shims 实施计划

> **面向 AI 工作者：** 必须使用 `fspec-subagent-driven-development-fe`（推荐）或 `fspec-execute-plans-fe` 逐任务实施本计划。步骤使用复选框（`- [ ]`）语法跟踪进度。

**目标：** 在 EnvManager 中提供 Windows User scope 的 Command Shims 管理，使短命令稳定调用指定可执行文件和固定参数，并安全转发调用参数与退出码。

**架构：** Rust 侧新增独立的 `CommandShimStore`，在 `%APPDATA%\EnvManager\command-shims.json` 保存结构化配置，在 `%LOCALAPPDATA%\EnvManager\bin` 原子生成带所有权标识的 `.cmd` 和 Git Bash 无扩展名 wrapper；所有配置和文件变更由跨进程写锁保护。首次保存通过现有 `EnvironmentService` 事务性地将受管目录加入 User `PATH`。React 侧新增独立导航、表格和编辑弹窗，通过三个 Tauri command 完成查询、保存和删除。

**技术栈：** Rust 2024、Serde、Tauri 2、React 19、TypeScript、Vitest、Windows Registry 与 batch wrapper。
