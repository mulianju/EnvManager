## 原始输入与来源摘要

### 原始需求

用户希望在 EnvManager 中配置一个名为 `sharedev` 的命令，使终端调用 `sharedev` 时，固定使用指定 Node.js 可执行文件运行指定 JavaScript 文件，并把调用参数继续传递给脚本。

示例目标：

```text
sharedev -> C:\Users\mulia\scoop\apps\nodejs-lts\current\node.exe
            D:\work\work\git\fe-paas\web-ide\packages\share-dev-cli\dist\sharedev.js
```

### 来源摘要

| 来源类型 | 标识 | 摘要 | 是否已核对 |
|----------|------|------|------------|
| 用户沟通 | 当前会话 | 环境变量本身不能注册终端命令，需要 EnvManager 提供额外能力 | 是 |
| 项目现状 | EnvManager | 当前产品管理 Windows User/System Registry 环境变量，尚无命令 Shim 管理能力 | 是 |

## 核心目标

- 让开发者用稳定、短小的命令名调用由指定运行时和脚本组成的工具。
- 命令解析不依赖系统默认 Node.js，也不要求用户手工维护 `.cmd` 文件和 `PATH`。
- 生成物可追踪、可校验、可安全更新和删除，不覆盖非 EnvManager 管理的文件。
